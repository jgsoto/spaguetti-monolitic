# Spaghetti Version – To-Do CRUD

This branch contains a simple To-Do CRUD application implemented using a **spaghetti code approach**.

## Description

All logic is handled inside a single controller, including:

* Request handling
* Validation
* Business logic
* Data storage (in-memory)

## Characteristics

* No separation of concerns
* High coupling between components
* Difficult to maintain and scale
* Limited testability

## Purpose

This version is intentionally designed to demonstrate poor structure, and serves as a baseline for comparison with a layered architecture implementation.
